# Dataset Information

## Dataset Overview

This project uses LinkedIn job market data collected through an API and contains information about job postings across India.

The dataset provides insights into:

* Job market trends
* Industry demand
* Company hiring patterns
* Geographical distribution of jobs
* Applicant behavior
* Work arrangements
* Experience requirements

## Dataset Features

The dataset contains information such as:

* Job Title
* Company Name
* Industry Sector
* Location
* Experience Level
* Contract Type
* Work Type
* Applications Count
* Job Description
* Posting Date

## Dataset Source

LinkedIn Jobs Data India Dataset

## Purpose

The dataset was used to analyze hiring trends, applicant behavior, sector growth, job demand, and geographical opportunities across India.
