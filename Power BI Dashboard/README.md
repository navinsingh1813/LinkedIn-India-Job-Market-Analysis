# Power BI Dashboard

## Dashboard Overview

This folder contains the Power BI dashboard developed for analyzing the LinkedIn Job Market in India.

The dashboard focuses on:

* Company Analysis
* Industry Analysis
* Geographical Distribution
* Work Type Analysis
* Job Demand Analysis
* Applicant Analysis

## Dashboard Pages

### Page 1

Project Navigation Page

### Page 2

Company & Sector Analysis

### Page 3

Geographical & Work Type Analysis

### Page 4

Job Role & Applicant Analysis

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Data Modeling
* Data Visualization

## Outcome

The dashboard provides interactive insights into hiring trends and employment opportunities across India.
